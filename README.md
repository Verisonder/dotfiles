# SR dotfiles

Hyprland on Fedora with the Omarchy look: a flat top bar, square windows, 19 themes that recolour
the whole desktop, Walker menus and a settings menu. Hyprland 0.56 with the Lua config.

## Install

On Fedora:

```bash
git clone https://github.com/Verisonder/dotfiles.git ~/dotfiles
bash ~/dotfiles/install.sh
```

Then log out and pick **Hyprland (uwsm)** at the login screen. Files the installer would replace
are moved to `~/dotfiles-backup-<time>/` first.

Every config is a symlink into `~/dotfiles` (GNU Stow), so editing a config edits the repo.
Save changes with `git -C ~/dotfiles commit -am "..." && git -C ~/dotfiles push`.

## Keys

| Keys | What it does |
|---|---|
| `SUPER + Space` / click the SR logo | App menu (`SHIFT`+click an app: open, info, hide, uninstall) |
| `SUPER + I` / right-click the SR logo | Settings: theme, wallpaper, keybindings, configs, hidden apps, reload |
| `SUPER + Return` | Terminal (kitty) |
| `CTRL + ALT + F` | Files (Dolphin) |
| `CTRL + ALT + B` | Browser (Helium) |
| `SUPER + V` | Clipboard history |
| `SUPER + Escape` | Power menu |
| `SUPER + L` | Lock |
| `SUPER + Q` | Close window |
| `SUPER + F` | Fullscreen |
| `SUPER + S` | Float / tile |
| `SUPER + arrows` / `SUPER + SHIFT + arrows` | Focus / move windows |
| `SUPER + 1…0` | Go to desktop |
| `SUPER + SHIFT + 1…0` | Move the window to a desktop and follow it |
| `SUPER + ALT + 1…0` | Send the window to a desktop |
| Hold `SUPER`, drag a window, press a number | Take the window to that desktop |
| `ALT + Tab` / `ALT + SHIFT + Tab` | Next / previous desktop |
| `SUPER + CTRL + A / W / B / T` | Sound / Wi-Fi / Bluetooth / btop |
| `SUPER + N` / `SUPER + SHIFT + N` | Show or hide the bar / clear notifications |
| `Print` / `SUPER + Print` | Screenshot to file / to clipboard |

All shortcuts live in `hypr/.config/hypr/keybinds.lua` (also under Settings > Keybindings).

## What's in here

| Folder | Contents |
|---|---|
| `hypr` | Hyprland (`hyprland.lua`, `keybinds.lua`), lock screen, idle |
| `waybar` | Bar layout and style, power menu |
| `walker`, `elephant` | Launcher, its theme and the SR menus (apps, themes, wallpapers) |
| `mako` | Notifications |
| `kitty`, `fish`, `starship`, `fastfetch` | Terminal, shell, prompt, system info with the SR logo |
| `wiremix` | Sound panel |
| `autostart` | Walker service, tray-applet overrides |
| `bin` | `sr-settings`, `sr-theme-set`, `sr-apps`, `sr-launcher`, `sr-tui`, `sr-wallpaper-set` |
| `fonts` | SR logo font for the bar |

Theme colours are generated by `sr-theme-set` into files that are not tracked
(`waybar/colors.css`, `mako/config`, `hypr/theme.lua`, `hypr/hyprlock-colors.conf`,
`kitty/theme.conf`, Walker, GTK and KDE colours), so switching themes doesn't change the repo.
